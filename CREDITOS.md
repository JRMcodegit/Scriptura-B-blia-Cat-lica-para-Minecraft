# Créditos

## Projeto

**Scriptura — Bíblia Católica para Minecraft**  
Organização, integração com Minecraft, ferramentas e manutenção: **JRMcodegit**.

## Texto bíblico

Tradução histórica associada a Padre António Pereira de Figueiredo (1725–1797), tradutor da Vulgata para o português.

## Fontes eletrônicas consultadas

- Iter Fidei: https://iterfidei.com/pt/biblia/
- Bíblia Traduzida: https://bibliatraduzida.com/figueiredo/

A atribuição identifica as fontes consultadas e não significa que os sites sejam autores do datapack, parceiros ou apoiadores do projeto.

- Minecraft Java Edition — plataforma de destino.
- Horizon Client — implementação alternativa usada para testar compatibilidade, quando aplicável.
